System Design

How semprox Works Under the Hood

Engineered in Rust with Axum, FastEmbed (ONNX Runtime), and SIMD-accelerated normalized dot-product search.

Step 01

Client Request

Standard OpenAI SDK or curl client sends a chat completion request to /v1/chat/completions.

Step 02

Local ONNX Embedding

FastEmbed generates an $L_2$-normalized 384-dimensional dense vector locally on CPU in ~15ms without external API calls.

Step 03

Vector Cache Scan

Scans in-memory vectors using dot product ($\vec{u} \cdot \vec{v}$). Evaluates whether best similarity $\ge$ configured threshold.

Step 04

Instant Hit / Upstream Miss

If matched: synthesized response returned in < 5ms. If missed: forwards to upstream LLM, streams tokens, and caches the response.

Features

Built for Production Scale

Everything you need to deploy enterprise semantic caching with zero operational headache.

⚡

Ultra-Low Latency

In-memory vector lookup takes sub-milliseconds. Saves up to 4,000ms compared to a live round-trip to cloud LLM providers.

🎯

Zero Vector DB Setup

No external Redis, Pinecone, Milvus, or Qdrant infrastructure to provision, manage, or pay for. Self-contained in Rust.

🌊

Bidirectional SSE Streaming

Full support for streaming completions (stream: true). Reads chunks in real-time, extracts answer tokens, and caches seamlessly.

🧠

Local CPU Embedding

Runs quantized ONNX models (AllMiniLML6V2Q / BGESmall) directly on standard server CPUs without requiring expensive GPUs.

🧹

Bounded LRU Eviction

Configurable --max-cache-size ensures your cache memory stays bounded with automatic thread-safe LRU eviction.

📊

Prometheus Observability

Exposes production metrics out of the box at /metrics (hits, misses, requests, cache size) and readiness at /health.

Integration

Up and Running in 30 Seconds

Drop into your existing OpenAI SDK codebase with a single line base URL change.

curl http://localhost:8080/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "user", "content": "Explain Kubernetes in one sentence"}
    ],
    "stream": true
  }'
